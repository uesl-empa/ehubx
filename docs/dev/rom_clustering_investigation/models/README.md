# Test models

Input files only. Run them through `scripts/run_case.py` (or `scripts/romlab.py`).

| Model | Stages | Capacities | Storage | Used in | Notes |
|---|---|---|---|---|---|
| `examples/clustering_demo` (case `demo`) | 1 | see example | EBM storage (X2) | E0, E1, E4, E7 | repo example; has a network link, so no regret runs |
| `ms3/` | 2 | fixed | yes | E0, E1 | synthetic; S2 export price = import price / 2; see `ms3/README.md` |
| `swissx/` | 4 | – | – | E0, E1, E4 (clustering only) | real SwissX profiles, git-ignored; see `swissx/README.md` |
| `pv_bat/` | 1 | free | Bat (≤ 2000 kWh), TES (≤ 1500 kWh) | E1b, E4, E7 | synthetic, see below |
| `pv_bat_nostor/` | 1 | free | none | E7 | `pv_bat` without Bat and TES |
| `pv_bat_bak1/` | 1 | free | as `pv_bat` | E1c | `pv_bat` with emergency heat at 1.0 instead of 5.0 CHF/kWh |
| `demo_nostor/` | 1 | free | none | E7 | `demo` without the EBM storage (X2) |

`pv_bat`, `pv_bat_nostor`, `pv_bat_bak1` and `demo_nostor` are generated by
`scripts/make_models.py` (seed 42); edit that script rather than the files.

**`pv_bat`**: one hub with PV, battery, heat pump, gas boiler and thermal
storage. Hourly electricity price profile, gas at 0.11 CHF/kWh, export at
0.02 CHF/kWh. Heat demand has a winter cold snap (peak 131.4 kW). Heat can
also be imported as emergency backup at 5.0 CHF/kWh (about 40× the normal heat
cost). This keeps the full-horizon regret solve always feasible, but it also
means a small heating under-sizing shows up as a large cost (see E1b, E1c).
